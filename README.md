# Paradise Nursery

Paradise Nursery is a plant shop application that allows users to browse houseplants, add plants to a shopping cart, update quantities, and manage their purchases.

## Project Name

Paradise Nursery

## Project Description

Paradise Nursery is an online plant shopping application built with React and Redux. Users can explore different categories of houseplants, view plant information, add plants to their cart, change quantities, remove products, and view the total cost.

## Main Features

- Paradise Nursery landing page
- Company information page
- Plant product listing
- Three plant categories
- Multiple houseplants in each category
- Add to Cart functionality
- Dynamic cart item count
- Shopping cart
- Increase and decrease quantity
- Delete cart items
- Total price calculation
- Checkout message
- Continue Shopping functionality

## Technologies Used

- React
- JavaScript
- CSS
- Redux Toolkit
- React Redux
- Vite
